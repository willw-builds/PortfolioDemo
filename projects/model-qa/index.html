Review guide

Why use this after Excel?

Excel Formula Auditing is better for tracing precedents, following dependents, evaluating a formula, and correcting a workbook in place. This prototype does a different job: it scans the workbook in one pass and creates a review queue with sheet names, cell references, evidence, and suggested follow-up.

If your edition of Excel for Windows includes Spreadsheet Inquire, use it. This prototype is most useful as a lightweight second check, a browser option for people without Inquire, or a structured handoff between a model author and reviewer.

01

Run Excel checks first

Recalculate the workbook, inspect visible Excel errors, and use Trace Precedents or Trace Dependents when a specific formula looks wrong.

02

Select the workbook here

The browser reads the selected file into memory and applies the enabled structural checks. The workbook is not sent to a server or saved by this site.

03

Review, do not auto-fix

Open each flagged cell in Excel and decide whether it is an error or an intentional exception. Hard-codes and pattern changes can be valid.

04

Export the review list

Use the report to document what was checked, assign follow-up, or discuss the model with another reviewer.

What it checks today

Error tokens, formula gaps, copied-formula pattern changes, suspicious numeric literals, percentage magnitude signals, and direct division by zero.

What it does not prove

A clean report does not mean the model is correct. The prototype cannot confirm valuation logic, forecast assumptions, accounting treatment, data quality, or whether an unusual formula is intentional.

Planned product direction

Finance-specific controls such as sources and uses, debt roll-forwards, cash bridges, forecast transitions, assumptions-sheet linkage, and materiality-based prioritization are not implemented yet.

How local processing works

The browser opens the file with its local file API and parses the workbook in memory. This page makes network requests for page assets such as fonts and the spreadsheet parsing library, but the workbook bytes are not included in those requests. The site has no workbook upload endpoint or storage service.
