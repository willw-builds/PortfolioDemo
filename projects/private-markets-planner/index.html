Product case study

Why this trial exists

A small planning tool can reveal more than a static performance report when the user needs to make the next commitment decision.

01

User and problem

Built for an allocator or portfolio manager who needs a quick view of fund performance, uncalled exposure, and potential future cash demands.

02

Product decision

The first version asks for nine inputs and keeps every calculation in the browser. It favors an understandable scenario over a detailed institutional model.

03

What I left out

No fees, waterfall, XIRR, currency conversion, or multi-fund aggregation. Those features add value only after the core pacing view proves useful.

04

How I would measure it

Track completed scenarios, time to first useful comparison, repeat scenario runs, and whether users can explain the difference between DPI and TVPI afterward.

05

What comes next

Add CSV cash-flow upload, a commitment calendar, and a multi-fund portfolio view. User interviews would determine which one earns the next build cycle.
